# Autonomous Multimodal Scientific Discovery Agent

## Project Overview

The Autonomous Multimodal Scientific Discovery Agent is an AI-powered research assistance system designed to process scientific research papers, extract meaningful information, and support scientific knowledge discovery.

The system aims to simplify research workflows by combining document processing, data extraction, embeddings, and AI-based analysis.

## Objectives

- Automate scientific research paper processing.
- Extract useful information from research documents.
- Generate embeddings for semantic representation.
- Support research analysis and knowledge discovery.
- Provide an interactive dashboard for users.
- Organize research information for easier retrieval.

## Key Features

- Scientific paper ingestion
- Research document preprocessing
- Text extraction and cleaning
- Embedding generation
- Research analysis
- Interactive Streamlit dashboard

## Installation

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Navigate to the project:

```bash
cd AutoScientist-AI
```

3. Create a virtual environment:

```bash
python -m venv venv
```

4. Activate the environment on Windows:

```bash
venv\Scripts\activate
```

5. Install dependencies:

```bash
pip install -r requirements.txt
```

## Running the Application

```bash
streamlit run dashboard/app.py
```
